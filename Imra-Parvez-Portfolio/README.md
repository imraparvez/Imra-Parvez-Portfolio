# Imra Parvez — Student Portfolio

A responsive student portfolio built with separate HTML, CSS and JavaScript files.

## Folder structure

```text
Imra-Parvez-Portfolio/
├── index.html
├── style.css
├── script.js
├── README.md
└── resume/
    └── Imra-Parvez-Resume.pdf
```

## Run in VS Code with Live Server

1. Extract `Imra-Parvez-Portfolio.zip`.
2. Open VS Code.
3. Choose **File → Open Folder** and select the extracted `Imra-Parvez-Portfolio` folder.
4. If Live Server is not installed, open Extensions (`Ctrl + Shift + X`), search for **Live Server** by Ritwick Dey, and install it.
5. Open `index.html`.
6. Right-click inside the file and choose **Open with Live Server**.
7. Your portfolio will open in your browser. Save changes and Live Server will refresh the page.

## Personalisation notes

- Update the email, LinkedIn and GitHub URLs in `index.html` if they change.
- Project cards link to the supplied GitHub profile because individual public repository links were not supplied.
- The E-Waste project is not included because its status and confirmed details are still unknown.
- No certifications, awards, internships or unverified experience have been invented. Add them when you have confirmed information.
- The resume PDF contains only the information provided for this portfolio. It is a starter resume, not a claim of a complete employment history.
